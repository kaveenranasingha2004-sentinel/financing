# Layer 4a — Technical Analysis Addendum

_Version 1.0 — 2026-09-15. Written after a technical-analysis seminar covering five standard TA inputs: price/volume, momentum, support/resistance, trend, volatility. This addendum maps each into the existing five-layer system rather than creating a parallel one._

---

## 0. The governing rule, stated first

**Technical analysis may inform timing, sizing, and cross-checks. It may never create or move a floor.**

The floor answers _"what do I require, given the business and the bond market"_ (Layer 4, Step 0). Price action answers _"what is the crowd doing right now."_ These are different questions. Collapsing them is a named failure mode already caught once in this vault — **SUN's original 28.00 "floor" was later found to be a mislabeled stop-loss**, not a valuation. This addendum exists so that mistake has a permanent guardrail instead of being re-discovered per file.

Where TA and Layer 4 numbers must coexist on the same name (see §5, the JKH case), they are written as two separately labeled numbers, never merged into one.

## 2. Layer 1 — formalize price, volume, and momentum

Layer 1's daily 10-minute scan already collects most of this. Standardize the output to four lines, every time, rather than ad hoc prose:

1. **Turnover** vs. YTD daily average (flag if <50% or >150%)
2. **Breadth** — positive vs. negative contributors
3. **Foreign flow**, decomposed against the day's crossings table before trusting the headline number (per the macro dashboard's own standing discipline — large block trades have repeatedly matched foreign-sell headlines almost exactly)
4. **RSI** (or equivalent momentum read) on the index and on any name with an open tranche

This does not change Layer 1's purpose. It just makes momentum a named, consistent field instead of an occasional aside.

## 3. Layer 4 — support/resistance as a ceiling cross-check, formally scoped

**Rule, promoted from implicit practice to written rule:**

> Support/resistance may corroborate a ceiling already derived from sustainable earnings. It may never substitute for that derivation, and it may never touch a floor.

Precedent already in the vault: UAL's ceiling (78–80) noted the Q1 high of 83.20 as a soft confirming reference, not an input to the number itself. That is the correct shape going forward — cited _after_ the earnings-yield ceiling is set, as a "does the market's own memory agree" check, never before.

**Explicitly forbidden:** using a prior low, a round number, or a chart level to set or defend a floor. A floor is earnings × multiple, full stop (Layer 4, Steps 2–3).

## 4. Layer 5 — volatility (sizing) and support/resistance (order placement)

This is genuinely new — volatility has no home yet. Two additions to Layer 5's existing rules, not new rules:

- **Volatility → position sizing.** A name with a wide historical trading range (SERV's 14.00–17.00 quarterly range on a Rs. 15 stock; ALUM's 16.00–19.90) gets tighter sizing within the existing "max ½ of available cash, max two tranches" ceiling — not a new sizing rule, just a stricter application of the one that exists.
- **Support/resistance → limit placement.** Once a floor is confirmed as the buy level, a nearby chart support level can inform _where inside that zone_ to place the limit order (e.g., clustering just above a level the market has already defended) — timing within an already-approved decision, never a reason to buy above the floor or skip it.

**Trend gets no new home.** Per the standing warning that two-day horizons are noise plus cost, and the discipline already applied to every trend observation in this vault (DIPD's downtrend "isn't a timing call"), trend commentary stays narrative color only — visible in files for context, never decision-bearing.

## 5. Retrofit action — JKH's unresolved stop-loss/floor conflict

JKH's file already names the problem this addendum is meant to prevent: a 19.50 technical stop-loss sits next to a 17.00 fundamentals floor, flagged as "not resolved... should be consciously decided, not defaulted." Per the standing system warning (five_layer_system_procedure.md, "Standing warnings"): _if a stop-loss is wanted, it goes below the last tranche level, written in advance, as thesis-failure insurance_ — never the same number as, or positioned above, the floor.

**Open homework, carried from this addendum into JKH's file:** resolve the 19.50/17.00 conflict on next review. The corrected structure would be floor 17.00 (buy level, unchanged) with any technical stop written separately below the second tranche (15.30), if one is wanted at all — not at 19.50, which currently sits _above_ the floor and would trigger a sell on a name the fundamentals still call cheap.

---

## 6. What this addendum deliberately does not do

- Does not add a sixth layer. TA is distributed into Layers 1, 4, and 5 as cross-checks and mechanics, not elevated to its own decision layer.
- Does not change any existing floor or ceiling. No file's numbers move as a result of this document.
- Does not authorize chart-based entries outside the floor/ceiling band. "Price broke resistance" is not, and will not become, a buy signal in this system.

---

_One-line version: volume and momentum sharpen the daily read, support/resistance can nod at a ceiling and help place an order, volatility sizes the position — none of the five ever writes or moves a number that only sustainable earnings and the hurdle rate are allowed to write._
