# Layer 3a — Company Quality Checks Addendum
*Version 1.0 — 2026-09-19. Closes two gaps identified against a beginner fundamental-analysis checklist: neither is new information, both were previously handled reactively (only checked once a file already looked bad) rather than as a routine step on every company. This addendum makes both routine.*

---

## 0. Why these two, and not the others

The checklist that prompted this had five items. Three were already standing Layer 3 practice (profit trend, balance-sheet debt, multi-year sales/profit trend). Two were not:

1. **Cash-flow-vs-profit** — currently only surfaces in a file after it's already a visible problem (HAYL's operating-cash-flow reversal, SINS's −41.5bn, HAYC's −6.57bn). Never checked as a routine pass/fail on a name that looks clean.
2. **Moat / competitive durability** — not checked anywhere. No file currently reads the Chairman's Message or MD's Review specifically for a stated competitive-advantage argument.

Both become **standing steps inside Layer 3**, not a new layer, not a valuation input on their own.

---

## 1. Check A — Cash flow vs. reported profit

**Rule:** every company file states, explicitly and on every update, the relationship between operating cash flow and reported PAT for the latest full year and the latest interim — whether or not it's a problem. A clean result gets written down as "checked, clean" with the actual OCF figure; it does not get silently skipped because nothing is wrong.

**Procedure:**
1. Pull operating cash flow (from the cash flow statement) for the latest FY and latest interim.
2. Compare against reported PAT for the same periods. A business converting profit to cash roughly 1:1 over a multi-year view is healthy; a persistent, widening gap (profit rising while OCF stays flat, negative, or working-capital-consumed) is the named risk — same treatment as every other named risk in the floor-multiple discount (Layer 4, Step 3).
3. One quarter of negative OCF is not automatically a red flag (working-capital seasonality is real — HAYC's own file notes Q1 is typically the smaller build quarter for some businesses). The flag is for a **trend**: two or more consecutive periods, or a full-year reversal, per the same "wrong-but-still-fine" trigger discipline the rest of the system already uses — this does not move a floor on one bad quarter any more than any other risk does.
4. Where OCF is negative and the gap is being plugged with new borrowing (the HAYC/SINS/HAYL pattern), name that explicitly — it's a materially worse version of the same risk than negative OCF funded from existing cash.

**Where it lives in the file:** a one-line statement in the balance-sheet/leverage section of every file (existing section — no new section required), e.g. *"OCF vs PAT: Rs. X.Xbn vs Rs. Y.Ybn — [converting cleanly / diverging, Nth consecutive period]."* If it's a genuine risk, it also gets its own line in the named-risks list feeding the floor multiple, same as any other risk.

**Does not, by itself, move a floor or ceiling.** It becomes a named risk that feeds the multiple, same discipline as every other risk in the system — the check itself is just the routine step of looking, on every file, every time.

---

## 2. Check B — Moat / competitive durability

**Rule:** every company file names, in one line inside its "what the company actually is" section, whatever competitive-durability claim exists (or explicitly notes that none was found). The read is the Chairman's Message and the MD's/CEO's Review in the Annual Report — company-stated, not assumed.

**Procedure:**
1. Read the Chairman's Message and MD's/CEO's Review specifically for a competitive-position claim: cost leadership, brand strength, regulatory/license position (BOI concessions, a captive distribution network, a market-share number defended over multiple years), scale advantages, switching costs, or a genuinely differentiated asset (LIOC's CPSTL stake, JINS's agency network, HAYC's stated ~16% global activated-carbon share).
2. **Distinguish a claim from evidence.** A moat only counts if the report backs it with something checkable — a market-share figure, a multi-year margin advantage over named competitors, a regulatory document. A Chairman's Message asserting "market leadership" with nothing behind it is noted as *unevidenced*, not treated as a found moat.
3. Where a real, evidenced moat exists, it can support the same kind of quality offset already used elsewhere in this vault — UAL's "quality can justify a modest premium to neutral, but only when named and argued" (Layer 4, Step 3), or SINS's list of "offsetting positives" against its named risks. It is not automatically worth a specific multiple adjustment; it's evidence to weigh the same way those existing offsets already are.
4. Where no moat is found or claimed, say so plainly — "commodity business, no differentiated position identified" is a legitimate, useful finding, not a gap in the research.

**Where it lives in the file:** one line, "what the company actually is" section, every file. No new section required.

**Does not, by itself, move a floor or ceiling** any more than any other single qualitative input — it's one factor among the named risks/offsets already weighed in Step 3 of Layer 4.

---

## 3. Retrofit — how this applies to the existing 15 files

**Not a backfill sweep.** Per the vault's own working practice — a company gets whatever it needs done in one pass whenever it's next opened for any reason — both checks get added the next time each existing file is touched for its own scheduled reason (a new interim, a hurdle re-derivation, a trigger event), not as a standalone project to revisit all 15 files immediately.

**New files, starting now:** both checks are mandatory from the next file created or materially updated onward, no exception.

---

## 4. What this addendum deliberately does not do

- Does not create a new layer or a new file section — both checks slot into existing sections of the existing file format.
- Does not make either check a valuation input on its own — both feed the same named-risk/offset weighing Layer 4 already does, under the same trigger discipline as everything else.
- Does not retroactively change any current floor, ceiling, or verdict. Nothing here moves a number until a file is next opened and the checks are actually run against that company's own filings.

---

*One-line version: does cash back up the profit, and does the company actually have something a competitor can't easily take — both now get asked, out loud, on every file, instead of only surfacing when the answer is already bad.*
